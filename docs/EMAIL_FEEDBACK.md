# 邮件反馈流程

1. iOS 15：设置 → 隐私 → 分析与改进 → 分析数据；较新系统为「隐私与安全性」。找到最近的 Lexirus .ips，分享并存储到文件。
2. 访问官网崩溃反馈页，选择文件（JSON 格式，最多 5 MB）。
3. 本机提取技术字段并预览；官网不接收文件。
4. 下载 Lexirus-diagnostic.json 并确认保存。
5. 点击发邮件反馈，在邮件应用手动添加该文件，说明复现步骤，发送至 xzwdev@163.com。mailto 不附加文件，也不确认送达。
6. 找不到或不支持日志时，直接用邮件描述问题即可。需要删除邮件附件时回复原邮件。

2026-11-14 用户最终决定：只上线静态官网，上传暂用邮件。ECS 固定带宽计费已核实；未部署接收程序、未调整云资源或修复系统。部署接口的代码留在本地供未来单独评估，不属于本次公开发布内容。
